Step 1. For every open item, judge its evidence from the whole conversation and the new information, using `<EVIDENCE STRENGTH>`:
- "strength": the strongest positive evidence so far that you and the partner hold the same repaired interpretation (E0–E4). A repair having been sent is not evidence; silence is not acceptance.
- "evidence": name the strongest evidence type and what it showed.
- "outcome" from the O codebook: O1 when the evidence is enough for current purposes, given how important this item is (see `<EVIDENCE STRENGTH>`), and no counter-evidence stands, with "resolution" stating in one sentence what both now share that settles the problem: the interpretation, map fact, or reference it rests on (for example, that a landmark is placed differently on the two maps and which reference replaces it), not the route steps that followed. Evidence that shows only that the partner received the repair (E2 or weaker, such as a bare acknowledgement) does not resolve the doubt that opened the item, so it is not enough for O1. O2 when the interaction has visibly moved on and the item is no longer pursued although it was not solved; O3 when both positions are explicit and mutually understood but still differ, with "resolution" stating both positions and what was agreed to do; otherwise O4.

Step 2. Relate the current detection to the open items and the recently closed items. Open items: "merge" only when the new cue concerns the same disputed proposition, that is, when one answer would settle both (even with different H or W codes). If settling the item would still leave the new cue open (it concerns a later step, a different target, or another property of the same step), it is "new". Keep each item's proposition as stated; do not widen it to absorb a new question. Recently closed items: "merge" only when the new cue concerns the same proposition as that item, by the same test (one answer would settle both); this reopens the item, because the earlier repair did not hold, and its repairs still count. A different question about the same part of the task is "new". Use "none" only when the current H is H7.
